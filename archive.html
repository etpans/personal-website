Projects

  • Trove

    May 2026 – Present

    A classroom notes app built with TypeScript, Next.js, NestJS, and Expo for web and mobile. PostgreSQL and TypeORM manage class and student records, with JWT authentication and AWS S3 attachments. Helps teachers organize notes, files, and shared updates in one place.

    Source code

  • MyShell

    Jan 2026 – Apr 2026

    A Unix-style shell built in C on Linux, with pipes, I/O redirection, signal handling, and background job management. Used Valgrind and iterative tests to check memory safety and runtime behaviour.

    School project; source code not published.

  • Afraid of the Dark

    Sep 2025 – Oct 2025

    A terminal-based game written in RISC-V assembly, built around a grid, collectible items, a shadow monster, and a rising fear factor. Handles movement, item tracking, and game state through low-level assembly control flow.

    School project; source code not published.

  • Unite

    Feb 2025

    A campus event discovery app built at DeerHacks 2025 with React, Vite, Python Flask, and MySQL. Connects event and club data to an interactive map, search, and filtering to help UofT students find events on campus.

    Devpost

  • Proxima

    Aug 2022 – Nov 2022

    A Roblox UI library written in Lua, forked from Jan's uwuware. Added settings autoloading and UI animations, and fixed issues with sliders, tooltips, and keybinds.

  • Image Database

    Dec 2022 – Jan 2023

    An image upload and gallery project built with HTML, CSS, JavaScript, and PHP. An early build that runs locally, with no hosted server.
